## 二、命令参数格式

### 1. 不带值的短参数
一般作为开关使用。

语法：

```bash
-[参数名]
```

示例：

```bash
ls -a
```

### 2. 带值的短参数
用来传递具体参数值。

语法：

```bash
-[参数名] [参数值]
```

示例：

```bash
ls -n 10
```

### 3. 不带值的长参数
一般作为开关使用。

语法：

```bash
--[参数名]
```

示例：

```bash
ls --all
```

### 4. 带值的长参数
用来传递具体参数值。

语法：

```bash
--[参数名]=[参数值]
```

示例：

```bash
ls --block-size=KB
```

### 5. 位置参数
用于传递具体的操作对象。

语法：

```bash
[操作对象]
```

示例：

```bash
ls sample.txt
```

### 参数综合示例

```bash
ls -a -l --block-size=KB /home/chriskim
```

## 三、参数的简写写法

### 1. 合并多个短参数
多个短参数可以合并写在一起。

语法：

```bash
-[参数名][参数名]...
```

示例：

```bash
ls -alh
```

### 2. 不隔开的带值短参数
短参数和参数值之间完全不隔开。

语法：

```bash
-[参数名][参数值]
```

示例：

```bash
make -j16
```

### 3. 不用等号的带值长参数
长参数和参数值之间用空格隔开，不使用等号。

语法：

```bash
--[参数名] [参数值]
```

示例：

```bash
ls --block-size KB
```

前面的命令可以等价写成：

```bash
ls -al --block-size KB /home/chriskim
```

## 四、终端快捷键

### 自动补全与历史记录
- `Tab`：自动补全命令或文件名
- `↑`：向上翻阅历史命令
- `↓`：向下翻阅历史命令

### 光标移动
- `Home`：光标移动到命令开头
  - 替代快捷键：`Ctrl + A`
- `End`：光标移动到命令末尾
  - 替代快捷键：`Ctrl + E`
- `Ctrl + ←`：向左移动一个单词
- `Ctrl + →`：向右移动一个单词

### 复制粘贴
- `Ctrl + Insert`：复制选中的文字
- `Shift + Insert`：粘贴文字

### 清屏
可以使用：

```bash
Ctrl + L
```

或者执行命令：

```bash
clear
```

## 六、常用目录与文件命令

### cd：切换目录

```bash
cd 目录名
```

连续执行 `cd -`，会在当前目录和上一次所在目录之间来回切换。

### ls：打印目录内容

```bash
ls
```

以 `.` 开头的文件或目录是隐藏文件。

### ll：列表形式查看

```bash
ll
```

### l：网格形式查看

```bash
l
```

### -h：显示文件大小单位

```bash
ls -lh
```

### pwd：打印当前所在目录

```bash
pwd
```

### cat：查看纯文本文件，也可以连接文件

```bash
cat 文件名
```

## 七、新建目录与文件

### mkdir：新建目录

```bash
mkdir 目录名
```

`-p`：父目录不存在时一并创建，可以一次性创建多级目录。

```bash
mkdir -p a/b/c
```

### touch：新建空文件

```bash
touch 文件名
```
